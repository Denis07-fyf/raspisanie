# Моё расписание

Готовая статическая версия приложения для бесплатной публикации на GitHub Pages.

## Публикация

1. Создайте на GitHub новый публичный репозиторий `raspisanie`.
2. Распакуйте ZIP и загрузите все файлы **изнутри папки** в корень репозитория.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/(root)` и нажмите `Save`.
6. Через несколько минут сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/raspisanie/`.

Данные остаются в прежнем Supabase-проекте. Вход выполняется по PIN `1977`.

## Мгновенный запуск на телефоне

1. Один раз откройте сайт с интернетом и дождитесь расписания.
2. На iPhone: **Поделиться** → **На экран «Домой»** → **Добавить**.
3. Дальше открывайте расписание через значок на домашнем экране.

После первого полного открытия интерфейс загружается с устройства и работает без ожидания GitHub. Расписание и ДЗ показываются из локального кэша при действующей защищённой сессии. Для синхронизации изменений нужен интернет; PIN и код генератора не отключаются.

Окна между занятиями длительностью от 45 минут автоматически показываются отдельными карточками. Нажмите на окно, чтобы сохранить его как событие, изменить название, время, цвет, заметку и повторение.
