# Моё расписание

Готовая статическая версия приложения для бесплатной публикации на GitHub Pages.

## Публикация

1. Создайте на GitHub новый публичный репозиторий `raspisanie`.
2. Распакуйте ZIP и загрузите все файлы **изнутри папки** в корень репозитория.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/(root)` и нажмите `Save`.
6. Через несколько минут сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/raspisanie/`.

Данные остаются в прежнем Supabase-проекте. Вход выполняется по PIN `1977`.
